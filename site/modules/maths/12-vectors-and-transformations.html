Vectors and Transformations

Two topics that share one idea: movement described precisely. Column vectors and the "show by a vector method" proof sit near the end of Paper 1H, worth five marks each time. Transformations come earlier and are nearly free, as long as you say every detail and describe one transformation, not two.

02How it actually works

A vector is a movement: how far, and which way. Once you can add movements, you can find any route through a diagram, and proofs about parallel lines and straight lines become algebra. Transformations are the second half: four ways to move a shape, each with a fixed list of details the examiner is waiting for.

Notation in this module: AB→ is the vector from A to B (in the exam it is written with an arrow over it, as here). A bold lower-case letter such as a is a vector (handwritten with a wavy line underneath). 3−2 is a column vector: 3 right, 2 down.

What a vector is and how it is written

Spec 5.1A, 5.1B · 2018 Edexcel May 1H Q17

A vector has both a size (magnitude) and a direction; a column vector gives the movement across on top and the movement up underneath.

  1. Top number: x-movement. Positive is right, negative is left.
  2. Bottom number: y-movement. Positive is up, negative is down.
  3. To get the vector from A to B, subtract coordinates: AB→ = B − A (end minus start).
  4. Going the opposite way flips every sign: BA→ = −AB→.

Worked example: A(2, −1) and B(7, 3)

1. AB→ = end − start = 7−23−(−1) = 54 1

2. BA→ = −AB→ = −5−4

A number without direction, such as a length or a scale factor, is a scalar.

✗ AB→ = A − B, giving −5−4: start minus end reverses the direction.
✗ Writing a column vector as coordinates, (5, 4), or with a fraction line between the numbers.
✓ AB→ = B − A = 54, written as a column with no line.

Adding, subtracting and multiplying by a number

Spec 5.1C, 5.1D

Column vectors are added, subtracted and multiplied by a scalar one row at a time.

  1. Multiply first: every number in the vector is multiplied by the scalar.
  2. Then add or subtract the tops, and separately the bottoms.
  3. Take extra care with "minus a negative".

Worked example: a = 3−2, b = −14. Find 2a − 3b

1. 2a = 6−4 and 3b = −312 M1

2. Tops: 6 − (−3) = 9. Bottoms: −4 − 12 = −16.

3. 2a − 3b = 9−16 A1

A scalar multiple points the same way (or exactly the opposite way, if negative). That single fact is behind every parallel-line proof later on.

✗ 6 − (−3) = 3.
✓ 6 − (−3) = 6 + 3 = 9. Write the subtraction with brackets before you simplify it.

Magnitude (modulus) of a vector

Spec 5.1E

The magnitude of a vector is its length, found by Pythagoras on its two components.

Magnitude of a column vector|xy| = √(x2 + y2)x and y are the components · the answer is a length, so it is never negative
  1. Simplify the vector into a single column first.
  2. Square each component. A negative squared is positive.
  3. Add, square root, and round only at the end.

Worked example: a = 31, b = −25. Find |2a − b|

1. 2a − b = 6−(−2)2−5 = 8−3 M1

2. √(82 + (−3)2) = √(64 + 9) = √73 M1

3. = 8.544… = 8.54 (3 s.f.) A1

✗ |a| + |b| for |a + b|. Two separate lengths do not add unless the vectors point the same way.
✗ √(82 − 32): the minus sign disappears when you square.
✓ Combine the vectors first, then use √(x2 + y2).

Using vectors to find coordinates

Spec 5.1B, 5.1F · 2018 Edexcel May 1H Q17(a)

A position plus a vector gives a new position: start point + movement = end point.

  1. Write down what you know as a chain of points, e.g. B, then A, then C.
  2. To go backwards along a vector, subtract it. To go forwards, add it.
  3. In a parallelogram ABCD, opposite sides are equal vectors: AB→ = DC→ and AD→ = BC→.

Worked example: AB→ = 35, AC→ = 98, B is (4, 6). Find C.

1. A = B − AB→ = (4 − 3, 6 − 5) = (1, 1) M1

2. C = A + AC→ = (1 + 9, 1 + 8) M1

3. C = (10, 9) A1

Or in one step: BC→ = BA→ + AC→ = −3+9−5+8 = 63, and (4 + 6, 6 + 3) = (10, 9).

Routes through a diagram (resultant vectors)

Spec 5.1F · 2016 Edexcel SAM 1H Q22

To find a vector between two points, travel there along any route made of vectors you already know.

  1. Write the route as a sum of letters: OC→ = OA→ + AB→ + BC→. The inner letters must chain (A to A, B to B).
  2. Replace each piece with its vector. Going against an arrow, use the negative.
  3. Collect the a terms and the b terms and simplify.

Worked example: OA→ = 3a, AB→ = 2b, BC→ = c

1. OC→ = OA→ + AB→ + BC→ = 3a + 2b + c

2. CA→ = CB→ + BA→ = −c − 2b

The most-used route of all: if OA→ = a and OB→ = b, then AB→ = AO→ + OB→ = −a + b = b − a.

✗ AB→ = a − b when OA→ = a and OB→ = b.
✓ AB→ = b − a. "End minus start" works for position vectors too.

Points that divide a line in a ratio

Spec 5.1F, 5.1G · 2016 Edexcel SAM 1H Q22 · 2016 Edexcel Jan 3HR Q19

If P divides AB in the ratio m : n, then AP→ is m/(m + n) of AB→.

  1. Add the ratio parts to get the denominator: AP : PB = 2 : 3 means AP is 2/5 of AB, not 2/3.
  2. Find the whole vector AB→ first, as a route.
  3. AP→ = (fraction) × AB→, then OP→ = OA→ + AP→.
  4. The midpoint is the ratio 1 : 1, so its fraction is 1/2.

Worked example: OA→ = a, OB→ = b, P on AB with AP : PB = 1 : 3. Find OP→.

1. AB→ = b − a B1

2. AP→ = 1/4(b − a), because 1 + 3 = 4 parts M1

3. OP→ = a + 1/4(b − a) = 3/4 a + 1/4 b A1

Check: the coefficients add up to 1 (3/4 + 1/4). For a point on the line AB they always do.

✗ AP : PB = 1 : 3, so AP→ = 1/3 AB→.
✓ 1 : 3 is 4 parts in total, so AP→ = 1/4 AB→ and PB→ = 3/4 AB→.

Proving two lines are parallel

Spec 5.1G · 2016 Edexcel SAM 1H Q22 · 2014 Edexcel Jan 3H Q21

Two vectors are parallel if one is a scalar multiple of the other, so the proof is: find both vectors, then show one equals a number times the other.

  1. Find the first vector by a route, in terms of a and b. Simplify fully.
  2. Find the second vector the same way.
  3. Factorise each so the same bracket appears, e.g. 2(b + 2a) and 3(b + 2a).
  4. Write the conclusion: "AE→ = 2/3 BC→, so AE is parallel to BC."

Worked example: trapezium ABCD, AB→ = 6a, AD→ = 2b, DC→ = 9a. E is on DB with DE : EB = 1 : 2. Show that AE is parallel to BC.

1. AE→ = AD→ + DE→ (a route) M1

2. DB→ = DA→ + AB→ = −2b + 6a, so DE→ = 1/3(6a − 2b) = 2a − 2/3b M1

3. AE→ = 2b + 2a − 2/3b = 2a + 4/3b A1

4. BC→ = BA→ + AD→ + DC→ = −6a + 2b + 9a = 3a + 2b M1

5. AE→ = 2/3(3a + 2b) = 2/3 BC→, so AE is parallel to BC A1

From the same mark scheme: "NB Correct expressions for BC and AE must be given".

✗ Finding both vectors and stopping. The last A1 needs the link and the word parallel.
✓ "AE→ = 2/3 BC→, a multiple, so AE is parallel to BC."

Proving three points lie on a straight line

Spec 5.1G · 2018 Edexcel May 1H Q17(b) · 2012 Edexcel Jan 4H Q22

Three points are on a straight line (collinear) if two of the vectors between them are parallel and share a point.

  1. Pick a point common to both vectors, e.g. AB→ and AE→ both start at A.
  2. Find both vectors, as columns or in terms of a and b.
  3. Show one is a multiple of the other.
  4. Conclude: "parallel and they share the point A, so A, B and E are on a straight line".

Worked example: A is (1, 1), AB→ = 35, E is (31, 51). Prove that ABE is a straight line.

1. AE→ = 31−151−1 = 3050 M1

2. 3050 = 1035, so AE→ = 10AB→. The lines are parallel and both pass through A, so ABE is a straight line A1

The 2018 scheme also accepted comparing ratios: 50 ÷ 30 = 5 ÷ 3, so the gradients match.

✗ "AE→ = 10AB→ so they are parallel." Parallel lines can be side by side.
✓ "…parallel, and share the point A, so A, B and E are collinear."

The four transformations and what each one needs

Spec 5.2I, 5.2K, 5.2M · 2016 Edexcel SAM 2H Q6

"Describe fully" means the name of the transformation plus every detail that fixes it. Each detail is a separate B1.

TransformationDetails to stateShape after
Translationthe column vectorcongruent, same way round
Reflectionthe equation of the mirror linecongruent, flipped
Rotationcentre, angle, direction (clockwise or anticlockwise)congruent, turned
Enlargementcentre and scale factorsimilar: same angles, lengths × scale factor

Translations, reflections and rotations keep lengths and angles, so the image is congruent. Enlargements keep the angles but change the lengths.

✗ "It moved 4 right and 3 up." / "It turned 90°." / "It got bigger."
✓ "Translation by 43." / "Rotation 90° clockwise about (0, 0)." / "Enlargement, scale factor 2, centre (1, 3)."

Translations and reflections

Spec 5.2D–5.2H · 2016 Edexcel SAM 2H Q6(a)

A translation slides every point by the same column vector; a reflection puts every image point the same perpendicular distance from the mirror line on the other side.

  1. Translate: move every vertex by the vector, e.g. 52 is 5 right and 2 up. Then join up.
  2. Reflect: for each vertex, measure straight across (at 90°) to the mirror line, and go the same distance out the other side.
  3. Find a mirror line: it runs halfway between each point and its image. Give its equation.

Rotations

Spec 5.2A–5.2C · 2016 Edexcel SAM 2H Q6(b)

A rotation turns a shape about a fixed centre through an angle; anticlockwise counts as positive and clockwise as negative.

  1. Find the angle by comparing one side before and after (a vertical side that becomes horizontal has turned 90°).
  2. Find the direction: clockwise or anticlockwise. For 180° the direction does not matter.
  3. Find the centre with tracing paper, or where the perpendicular bisectors of point-to-image lines meet.
  4. Write all three: "Rotation, 90° anticlockwise, centre (−3, 0)."
About (0, 0)(x, y) goes to(4, 1) goes to
90° anticlockwise(−y, x)(−1, 4)
90° clockwise(y, −x)(1, −4)
180°(−x, −y)(−4, −1)

Worked example: rotate (4, 1) through 90° anticlockwise about (1, 2)

1. Position relative to the centre: (4 − 1, 1 − 2) = (3, −1).

2. Rotate that 90° anticlockwise: (3, −1) goes to (1, 3).

3. Add the centre back on: (1 + 1, 3 + 2) = (2, 5).

In the exam, use the tracing paper you are allowed: trace the shape, pin the centre with your pencil, turn 90°.

The SAM scheme accepted "+90°, 270° clockwise, −270°" for 90° anticlockwise. What it will not accept is an angle with no direction.

✗ "Rotation 90° about (−3, 0)."
✓ "Rotation 90° anticlockwise about (−3, 0)."

Enlargements, including fractional scale factors

Spec 5.2J–5.2L · 2014 Edexcel Jan 3H Q9 · 2016 Edexcel Jan 3HR Q3

An enlargement multiplies every distance from the centre by the scale factor; a scale factor between 0 and 1 makes the shape smaller but it is still called an enlargement.

Scale factorscale factor = image length ÷ object lengthgreater than 1 → bigger · between 0 and 1 → smaller · angles never change
  1. For each vertex, find the vector from the centre to it.
  2. Multiply that vector by the scale factor.
  3. Add the result to the centre to get the image vertex.
  4. To find the centre of a given enlargement: draw straight lines through each vertex and its image. They meet at the centre.

Worked example: enlarge (6, 4) with scale factor 1/2, centre (−2, 0)

1. From the centre to the point: (6 − (−2), 4 − 0) = (8, 4).

2. × 1/2: (4, 2).

3. Image = (−2 + 4, 0 + 2) = (2, 2).

Scale factor 3, centre (1, 1), point (2, 3): from the centre (1, 2), × 3 gives (3, 6), image (4, 7).

Going back the other way undoes the scale factor: if P to Q is scale factor 3, then Q to P is scale factor 1/3 with the same centre.

Negative scale factors are not on 4MA1. The spec says enlargements are "positive scale factor only (including fractions)", so you will not be asked for one.

✗ "Enlargement scale factor 1/3" with no centre: one mark of three.
✗ Calling scale factor 1/3 a "reduction" or "shrink". The mark scheme word is enlargement.
✓ "Enlargement, scale factor 1/3, centre (4, 3)."

Combining transformations into one

Spec 5.2M · 2014 Edexcel Jan 3H Q9(c)

When a question gives two transformations one after the other, find the single transformation by tracking a few vertices from the start to the end.

  1. Pick two or three vertices and apply the first transformation, then the second.
  2. Compare the start and end shapes: same size or not? Same way round or flipped? Turned?
  3. Name the single transformation and give all its details.

Useful results: reflect in the x-axis then the y-axis = rotation 180° about (0, 0). Two translations = one translation by the sum of the vectors.

04Understanding it

U1

Why is AB→ = b − a, and not a − b, when OA→ = a and OB→ = b?

Show answer

To get from A to B you can go A → O → B. A to O is backwards along a, so it is −a. O to B is b. The total is −a + b = b − a.

It is the same "end minus start" rule as for coordinates. a − b is BA→, the same length but pointing the other way.

U2

You have shown PQ→ = 3PR→. Why does that prove P, Q and R are on a straight line, but PQ→ = 3ST→ would not prove P, Q, S and T are?

Show answer

A multiple only proves the two lines point the same direction: they are parallel.

PQ and PR both pass through P, and two parallel lines through the same point must be the same line. So P, Q and R are collinear. PQ and ST share no point, so they could be two separate parallel lines, like the opposite sides of a parallelogram.

U3

P is on AB with AP : PB = 2 : 3. Why is AP→ = 2/5 AB→, not 2/3 AB→?

Show answer

The ratio splits the whole line into 2 + 3 = 5 equal parts. AP is 2 of those 5 parts, so it is 2/5 of AB.

2/3 compares AP with PB, not with the whole line. Check: 2/5 + 3/5 = 1, the whole of AB. With 2/3 and 3/3 you would get more than the whole line.

U4

Why does reflecting in the line y = x just swap the coordinates?

Show answer

The line y = x is at 45°, so it treats the two axes symmetrically. Reflecting in it swaps the x-axis and the y-axis over.

A point 3 across and 1 up becomes 1 across and 3 up: (3, 1) → (1, 3). Points on the line, like (2, 2), stay where they are, which is what you would expect of a mirror line.

U5

A shape is enlarged with scale factor 1/2. Why is this still called an enlargement, and what happens to its angles and its lengths?

Show answer

"Enlargement" is the name of the transformation type: every distance from the centre is multiplied by the same number. The number can be less than 1.

Lengths are all halved. Angles are unchanged, so the image is similar to the object. The position also moves, towards the centre, because each distance from the centre is halved too.

U6

Why does "rotation 90° clockwise about (0, 0), then translation by 20" score no marks, even if it does map A onto B?

Show answer

The question asks for the single transformation. The mark scheme says that if more than one transformation is given, no marks can be awarded.

A rotation followed by a translation is always equal to one rotation about a different centre. Find that centre (tracing paper, or perpendicular bisectors) and describe just the one rotation.

U7

a = 30 and b = 04. Why is |a + b| = 5 and not 7?

Show answer

a + b = 34, and its length is √(32 + 42) = 5.

Walking 3 east then 4 north covers 7, but you end up only 5 from where you started, in a straight line. Magnitudes only add when the vectors point the same way.

U8

Why do the perpendicular bisectors of the lines joining each point to its image meet at the centre of rotation?

Show answer

A rotation keeps each point the same distance from the centre. So the centre is equidistant from a point and its image.

All points equidistant from two points lie on their perpendicular bisector. The centre must be on every one of these bisectors, so it is where they cross. In the exam, tracing paper and trial and error is usually quicker.

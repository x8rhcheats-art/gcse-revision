Functions and Graphs

The widest algebra topic on the course, and one of the best-paying. There is a function question (f(3), fg, f−1, the excluded value) on almost every Higher paper, plus a straight-line or perpendicular-line question, a graph to read or draw, and a transformation. Most of it is a handful of routines, done carefully.

02How it actually works

A function is a machine: put x in, get f(x) out. Its graph plots every input against its output. Most of this module is reading that idea both ways. Algebra about f turns into a picture, and a picture turns into algebra: a crossing point is a solution, a gradient is a rate, and a shifted curve is a changed formula.

Function notation

Spec 3.2A, 3.2B · 2018 Edexcel May 1H Q14(a) · 2016 Edexcel SAM 2H Q17(a)

f(x) = … is a rule. f(a) means "put a in place of every x". f : x ↦ 3x2 − 2 is the same function written another way.

  1. For f(number): substitute, with brackets round negatives, and evaluate.
  2. For "solve f(x) = k": set the expression equal to k and solve the equation.
  3. For f(expression), such as f(2x) or f(x + 1): replace every x with the whole expression, in brackets.

Worked example: f(x) = 3x2 − 2

f(−2) = 3(−2)2 − 2 = 12 − 2 = 10

Solve f(x) = 25: 3x2 − 2 = 25, so x2 = 9, so x = 3 or x = −3

f(x + 1) = 3(x + 1)2 − 2 = 3x2 + 6x + 1

✗ f(−2) = 3 × −22 − 2 = −14. On a calculator, −22 is −4. Use (−2)2.
✗ f(x + 1) = 3x2 − 2 + 1. That is f(x) + 1, a different thing.

Domain, range and excluded values

Spec 3.2C · 2018 Edexcel May 1H Q14(d) · 2016 Edexcel SAM 2H Q17(b) · 2016 Edexcel Jan 3HR Q16 (old spec)

The domain is the set of inputs allowed. The range is the set of outputs produced. An input must be excluded if it would make you divide by zero or take the square root of a negative number.

  1. Fraction: set the denominator = 0 and solve. That x is excluded.
  2. Square root: the expression under the root must be ≥ 0. Solve the inequality. The values that break it are excluded.
  3. Range: think about which outputs are possible. x2 is never negative, and a fraction like 2x/(x − 1) never equals its "long-run" value.

Worked examples

f(x) = 3/(x − 2): x − 2 = 0, so x = 2 is excluded (SAM 2H Q17(b)).

g(x) = √(19 − x): need 19 − x ≥ 0, so x ≤ 19. The values that cannot be in any domain are x > 19 (2018 1H Q14(d)).

f(x) = x2 + 3: every output is at least 3, so the range is f(x) ≥ 3.

f(x) = 2x/(x − 1): x = 1 is excluded. Its inverse is x/(x − 2), which has 2 excluded, so 2 cannot be in the range of f (2016 Jan 3HR Q16(d)).

✗ "x = 19 is excluded" for √(19 − x). √0 = 0 is fine. It is x greater than 19 that fails.
✗ "x = −2 is excluded" for 3/(x − 2). Solve x − 2 = 0: x = +2.

Composite functions: fg(x)

Spec 3.2D · 2018 Edexcel May 1H Q14(c) · 2016 Edexcel SAM 2H Q17(c) · 2014 Edexcel Jan 3H Q20 (old spec)

fg(x) means f(g(x)): do g first, then put the answer into f. The function nearest the x acts first.

  1. For fg(number): work out g(number), then put that value into f.
  2. For fg(x): write f( … ) with the whole of g(x) inside, in brackets, wherever f has an x.
  3. Simplify: expand and collect.

Worked example: f(x) = 2x + 1 and g(x) = x2

fg(3) = f(9) = 19.   gf(3) = g(7) = 49. The order matters.

fg(x) = f(x2) = 2x2 + 1.   gf(x) = g(2x + 1) = (2x + 1)2 = 4x2 + 4x + 1

2018 1H Q14(c): f(x) = (3x − 5)/4 and g(x) = √(19 − x). Find fg(3).

g(3) = √16 = 4   (M1). f(4) = (12 − 5)/4 = 1.75   (A1)

✗ fg(3) worked out as g(f(3)). Read fg from the right: g is next to the x, so it goes first.
✗ fg(x) = f(x) × g(x). fg is a function of a function, not a product.

Inverse functions: f−1(x)

Spec 3.2D · 2018 Edexcel May 1H Q14(b) · 2016 Edexcel Jan 3HR Q16(c) (old spec)

The inverse function undoes f: if f turns 3 into 1, f−1 turns 1 back into 3. To find it, write y = f(x) and rearrange to make x the subject.

  1. Write y = f(x).
  2. Rearrange to make x the subject.
  3. Swap the letters: replace y with x and write f−1(x) = ….
  4. Check: put a number through f, then through f−1. You should get your number back.

Worked example: f(x) = (3x − 5)/4 (2018 1H Q14(b))

y = (3x − 5)/4 → 4y = 3x − 5 → 4y + 5 = 3x → x = (4y + 5)/3   (M1: correct first two steps)

f−1(x) = (4x + 5)/3   (A1)

Check: f(5) = 2.5 and f−1(2.5) = (10 + 5)/3 = 5 ✓

Worked example: f(x) = 2x/(x − 1), where x appears twice

y(x − 1) = 2x → xy − y = 2x → xy − 2x = y → x(y − 2) = y → x = y/(y − 2)

f−1(x) = x/(x − 2). Collect the x-terms on one side and factorise x out.

✗ f−1(x) = 4/(3x − 5), the reciprocal. f−1 is the inverse, not 1 ÷ f.
✗ Reversing the operations but not their order. For "× 3, then − 5, then ÷ 4", the inverse is "× 4, then + 5, then ÷ 3".

Straight lines: gradient, y = mx + c, midpoint and length

Spec 3.3 (Foundation E, G, H; Higher F) · 2016 Edexcel SAM 1H Q13(a) · 2013 Edexcel Jan 3H Q10 (old spec)

In y = mx + c, m is the gradient (the rise for each 1 across) and c is where the line crosses the y-axis. Two points fix a line.

Gradient between two points — memorisem = (y2 − y1) ÷ (x2 − x1)change in y ÷ change in x · keep the points in the same order top and bottom
Midpoint of a line segment — memoriseM = ((x1 + x2)/2, (y1 + y2)/2)the mean of the x-coordinates and the mean of the y-coordinates
Length of a line segment — memorised = √((x2 − x1)2 + (y2 − y1)2)Pythagoras on the horizontal and vertical steps
  1. Gradient from the two points.
  2. Find c: substitute one point into y = mx + c and solve. Or use y − y1 = m(x − x1).
  3. Rearrange to the form asked, e.g. ax + by = c with integers. Multiply through to clear fractions.
  4. To read m and c off an equation like 4x + 3y = 12, first rearrange to y = −(4/3)x + 4.

Worked example: SAM 1H Q13(a), the line through (−3, 5) and (1, 2), as ax + by = c

m = (2 − 5) ÷ (1 − (−3)) = −3/4   (M1)

2 = −¾(1) + c, so c = 11/4   (M1). y = −¾x + 11/4   (M1)

× 4: 4y = −3x + 11, so 3x + 4y = 11   (A1)

Worked example: A(2, −1) and B(8, 7)

Midpoint: ((2 + 8)/2, (−1 + 7)/2) = (5, 3). Gradient: 8/6 = 4/3. Length: √(62 + 82) = √100 = 10.

✗ Gradient = change in x ÷ change in y. It is up over across: change in y on top.
✗ For 2y = 6x + 5, "the gradient is 6". Divide by 2 first: y = 3x + 2.5, so m = 3.

Parallel and perpendicular lines

Spec 3.3G (Higher) · 2018 Edexcel May 1H Q20 · 2016 Edexcel SAM 1H Q13(b) · 2016 Edexcel Jan 4H Q12 (old spec)

Parallel lines have equal gradients. Perpendicular gradients multiply to −1: flip the fraction and change the sign.

Perpendicular gradients — memorisem1 × m2 = −1m2 = −1/m1 · e.g. 2/3 → −3/2 · parallel lines: m1 = m2
  1. Get the given line into y = mx + c form and read off m.
  2. Parallel: same m. Perpendicular: −1/m.
  3. Substitute the given point to find c.
  4. To show two lines are perpendicular, find both gradients and show that their product is −1.

Worked example: 2018 1H Q20, the line through (4, 37) perpendicular to 3y = 2x + 12

y = (2/3)x + 4, so the gradient is 2/3   (M1). Perpendicular gradient: −3/2   (M1)

37 = −3/2 × 4 + c, so c = 43   (M1). y = −(3/2)x + 43   (A1)

× 2: 3x + 2y = 86   (A1: integer coefficients, as asked)

SAM 1H Q13(b): show that y = 3x + 5 and 6y + 2x = 1 are perpendicular

6y = 1 − 2x, so y = 1/6 − (1/3)x, and the gradient is −1/3.   3 × (−1/3) = −1, so the lines are perpendicular. ✓

✗ Perpendicular to gradient 2/3 is −2/3, or 3/2. You need both steps: flip and change the sign, giving −3/2.
✗ Using the gradient of 3y = 2x + 12 as 2. Divide by 3 first.

Recognising the shapes of graphs

Plotting a curve from a table of values

Spec 3.3A (Higher) · 2018 Edexcel May 2H Q14(a), (b)

Complete the table by substituting each x, plot every point accurately, then join them with a smooth curve, not with straight segments.

  1. Substitute each x into the equation, with brackets for negatives. Use the given values as a check on your method.
  2. Plot each point to within half a small square.
  3. Join the points with a smooth curve through all of them. Turning points are rounded, not pointed.
  4. For y = k/x, do not join across x = 0. The two branches are separate.

Worked example: 2018 2H Q14(a), y = x3 − 2x2 − 3x + 4

x = −2: (−8) − 2(4) − 3(−2) + 4 = −8 − 8 + 6 + 4 = −6

x = −1: −1 − 2 + 3 + 4 = 4 · x = 1: 1 − 2 − 3 + 4 = 0 · x = 2: 8 − 8 − 6 + 4 = −2 · x = 3: 27 − 18 − 9 + 4 = 4

The scheme gave B2 for all five, or B1 for 2, 3 or 4 correct.

✗ −2x2 at x = −2 worked out as +8. The square is done first: −2 × 4 = −8.
✗ Joining the points with a ruler. The curve is marked on being smooth and passing through the points.

Solving equations with graphs

Spec 3.3E (Higher) · 2018 Edexcel May 2H Q14(c) · 2017 Edexcel Jan 4HR Q18 (old spec)

Where two graphs cross, their y-values are equal, so the x-coordinates of the crossing points solve "one equation = the other".

  1. Write the drawn graph's equation = the equation you must solve, and subtract to see what is left over.
  2. That leftover is the straight line to draw: drawn curve = new equation + leftover.
  3. Draw the line and read off the x-coordinates of every intersection.
  4. For "f(x) = k": draw the horizontal line y = k and count or read the crossings.

Worked example: 2018 2H Q14(c). The graph of y = x3 − 2x2 − 3x + 4 is drawn. Solve x3 − 2x2 − x + 1 = 0.

x3 − 2x2 − 3x + 4 = (x3 − 2x2 − x + 1) − 2x + 3

So when x3 − 2x2 − x + 1 = 0, the curve's y equals −2x + 3. Draw y = −2x + 3   (M1)

It crosses the curve at x ≈ −0.8, 0.6 and 2.2   (A1 A1: the scheme accepted −0.9 to −0.7, 0.4 to 0.7 and 2.1 to 2.4)

✗ Reading the y-coordinates of the crossings. The solutions are the x-values.
✗ Drawing y = 0 because the equation "equals 0". That solves the equation of the drawn curve, not the new one.

Trigonometric graphs

  2. sin: the second solution is 180° − first. cos: 360° − first. tan: first + 180°.

2018 1H Q18(b): read a, b, c from y = a sin(x − b)° + c

The graph ran from a minimum of −1 to a maximum of 3. The centre line is y = 1, so c = 1. The height from the centre is 2, so a = 2.

A normal sine wave rises through its centre line at 0°. This one does so at 90°, so it has been shifted 90° right: b = 90.

Transformations of graphs

Spec 3.3B, 3.3C (Higher) · 2018 Edexcel May 1H Q18(a) · 2016 Edexcel SAM 1H Q20

A change outside the brackets acts on y and does what you expect. A change inside the brackets acts on x and does the opposite.

New graphTransformationPoint (p, q) moves to
y = f(x) + aTranslation by (0, a): up a(p, q + a)

With a = −1: y = −f(x) reflects in the x-axis, and y = f(−x) reflects in the y-axis.

  1. Decide whether the change is outside (y-direction) or inside (x-direction, opposite way).
  2. Move the given point: change only the coordinate that is affected.
  3. When describing, use the full wording: "translation by the vector (0, −4)", or "stretch parallel to the y-axis, scale factor 2".

Worked example: SAM 1H Q20, maximum at (3, 5)

f(x + 3): inside, so left 3 → (0, 5).   2f(x): outside, so y doubles → (3, 10).

2018 1H Q18(a): minimum at (−2, −1)

f(x − 5): right 5 → (3, −1).   ½f(x): y halves → (−2, −0.5).

✗ f(x + 3) moves the graph 3 to the right. It moves it left: the old x = 3 now happens when x + 3 = 3, i.e. at x = 0.
✗ "It moves down 4" for f(x) − 4. Describe it as a translation with a vector.

Gradients of curves: drawing a tangent

Spec 3.3D (Higher) · 2016 Edexcel Jan 3H Q15(c) (old spec)

A curve's gradient changes from point to point. The gradient at a point is the gradient of the tangent there: a straight line that just touches the curve without crossing it.

  1. Lay a ruler against the curve at the point so that it touches but does not cut across, with equal gaps either side.
  2. Draw the tangent long: a longer line gives a more accurate gradient.
  3. Pick two points far apart on the tangent and use rise ÷ run.
  4. Check the sign: the curve going down to the right means a negative gradient.

Worked example: y = x2 at x = 2

The tangent at (2, 4) passes through (1, 0) and (3, 8). Gradient = (8 − 0) ÷ (3 − 1) = 4.

A drawn answer is an estimate, so the scheme accepts a range. Module 8 shows how differentiation gives the exact value.

✗ Using the chord between two points on the curve instead of a tangent. That gives the average gradient between the points, not the gradient at one of them.

Distance–time and speed–time graphs

Spec 3.3A (Foundation: "to include speed/time and distance/time graphs")

On a distance–time graph the gradient is the speed. On a speed–time graph the gradient is the acceleration and the area underneath is the distance travelled.

GraphGradient meansArea under it meansFlat line means
Distance–timeSpeed(nothing useful)Stationary
Speed–timeAcceleration (negative = deceleration)Distance travelledConstant speed
  1. Gradient = change in vertical ÷ change in horizontal, with units: m/s from a distance–time graph, m/s² from a speed–time graph.
  2. Area under a speed–time graph: split it into triangles, rectangles and trapezia and add them.
  3. Average speed = total distance ÷ total time, including any time spent stopped.

Worked example: 0 to 20 m/s in 10 s, 20 m/s for 30 s, then to rest in 5 s

Acceleration = 20 ÷ 10 = 2 m/s². Deceleration = 20 ÷ 5 = 4 m/s².

Distance = ½ × 10 × 20 + 30 × 20 + ½ × 5 × 20 = 100 + 600 + 50 = 750 m

Average speed = 750 ÷ 45 = 16.7 m/s (3 s.f.)

✗ Reading distance off the vertical axis of a speed–time graph. The vertical axis is speed. Distance is the area.
✗ Average speed = (0 + 20 + 0) ÷ 3. Use total distance ÷ total time.

03Cheat sheet

The routines

fg(x): g first, then f. f−1: y = f(x), make x the subject, swap the letters, check.

Excluded values: denominator = 0; expression under √ < 0.

Lines: m = Δy ÷ Δx; y = mx + c; midpoint is the mean of the coordinates; length = √(Δx2 + Δy2).

Parallel: same m. Perpendicular: m1m2 = −1 (flip and change the sign).

Graphical solutions: x-values of the crossings; the line to draw = drawn curve − new equation.

Trig: sin → 180 − x; cos → 360 − x; tan → x + 180.

Transformations: outside acts on y, as expected. Inside acts on x, the opposite way (f(x + a) goes left; f(ax) multiplies x by 1/a).

Speed–time: gradient = acceleration, area = distance.

04Understanding it

U1

f(x) = x + 5 and g(x) = 2x. Show that fg(x) ≠ gf(x), and explain why the order matters.

Show answer

fg(x) = f(2x) = 2x + 5.   gf(x) = g(x + 5) = 2x + 10.

"Double then add 5" is a different process from "add 5 then double". In gf, the 5 gets doubled too. The function written next to the x acts first, just as in f(g(x)).

U2

Why do you swap x and y at the end when finding an inverse, and how is the graph of f−1 related to the graph of f?

Show answer

The inverse takes f's outputs as its inputs. Making x the subject gives x in terms of y, the output. We then rename the input "x" so it can be written as a normal function, f−1(x).

Swapping x and y on a graph is a reflection in the line y = x. If (2, 7) is on y = f(x), then (7, 2) is on y = f−1(x).

U3

Why must x = 2 be excluded from the domain of f(x) = 3/(x − 2), but no value is excluded for f(x) = 3/(x2 + 1)?

Show answer

At x = 2 the first denominator is 0, and dividing by zero has no answer, so f(2) does not exist.

x2 + 1 is always at least 1, because x2 is never negative. The second denominator can never be 0, so every real x is allowed.

U4

Why do the gradients of perpendicular lines multiply to −1? Use a line of gradient 2.

Show answer

A line of gradient 2 goes 1 across and 2 up. Rotating that step by 90° turns "1 across, 2 up" into "2 across, 1 down", a gradient of −1/2.

The rotation swaps rise and run (flip the fraction) and reverses one direction (change the sign). 2 × (−1/2) = −1. The same happens for any gradient m, giving −1/m.

U5

Why does y = f(x − 5) move the graph 5 to the right, even though there is a minus sign?

Show answer

Whatever f did at x = 0, the new graph does when x − 5 = 0, i.e. at x = 5. Every feature now happens 5 later along the x-axis, so the graph has moved right.

That is why the 2018 minimum at (−2, −1) moved to (3, −1) for f(x − 5). Changes inside the bracket act on x in the opposite way to how they look.

U6

The graph of y = x2 is drawn. Why does drawing y = x + 6 on the same axes solve x2 − x − 6 = 0?

Show answer

At a crossing point both graphs have the same y, so x2 = x + 6, which rearranges to x2 − x − 6 = 0.

So the x-coordinates of the crossings are exactly the solutions: x = −2 and x = 3, which you can check by factorising (x − 3)(x + 2). The y-coordinates, 4 and 9, are not the answer.

U7

Why does the area under a speed–time graph give the distance travelled?

Show answer

At constant speed, distance = speed × time. On a speed–time graph that is a rectangle: height (speed) × width (time).

When the speed changes steadily, the shape becomes a triangle or trapezium, and its area is the average speed × time. Either way, the area measures distance, in m if the axes are in m/s and s.

U8

A calculator gives sin−1(0.5) = 30°. Why is 150° also a solution of sin x = 0.5, and how would you find all the solutions from 0° to 720°?

Show answer

The sine graph is symmetrical about 90°, so the height at 30° is repeated at 180° − 30° = 150°. The calculator only returns one value.

The wave repeats every 360°, so add 360° to each: 30°, 150°, 390°, 510°.

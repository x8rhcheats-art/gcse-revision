Sequences and Arithmetic Series

A small topic that earns a lot of marks. There is an easy nth-term question near the start of a paper, and a 5-mark arithmetic-series question near the end. Both are pure method: one formula to memorise, one on the formula sheet, and a pair of simultaneous equations.

02How it actually works

A sequence is a list of numbers that follow a rule. The rule can link each term to the one before (term-to-term) or give any term directly from its position (the nth term). An arithmetic sequence adds the same amount each time. That constant step is what makes a clean nth-term formula and a clean sum formula possible.

Term-to-term rules

Spec 3.1A, 3.1B (Foundation)

A term-to-term rule tells you how to get from one term to the next.

  1. Work out the differences between consecutive terms. If they are all the same, the rule is "add d".
  2. If not, try the ratio: does each term multiply by the same number?
  3. If neither works, look for special patterns: squares, cubes, powers, or adding the previous two terms.
SequenceRuleNext two terms

✗ "The rule is +4" for 5, 9, 13, 17 when the question asks for the nth term. That is the term-to-term rule, and it scores nothing there.
✓ Read which one is asked for. "Rule for the next term" means term-to-term. "Expression in terms of n" means the nth term.

Position-to-term rules: generating terms from the nth term

Spec 3.1A (Foundation) · 2015 Edexcel Jan 4HR Q5 (old spec)

An nth-term rule gives any term directly: replace n with the position number.

  1. Substitute n = 1, 2, 3, … in turn.
  2. Use brackets for anything squared: for n = 3 in 2n2 − 1, 2 × 32 − 1 = 17, not (2 × 3)2 − 1.

Worked examples

4n + 3: n = 1, 2, 3 gives 7, 11, 15. The differences are all 4, the number in front of n.

n2 + 3: n = 1 to 5 gives 4, 7, 12, 19, 28. The differences are 3, 5, 7, 9, which are not constant, so this is not arithmetic.

The 2015 pattern: row n was n × (n + 2) + 1 = (n + 1)2. Column 2 held 4, 9, 16, … so 676 = 262 is in row 25.

The nth term of a linear sequence

Spec 3.1C · 2016 Edexcel SAM 2H Q2

The nth term of a sequence that goes up by d each time is dn + (first term − d).

  1. Find the common difference d. That is the number in front of n.
  2. Write out the d times table underneath the sequence and see what you must add or subtract to get each term. That is the constant.
  3. Write dn + constant, then check it with n = 1 and n = 2.

Worked example: 5, 8, 11, 14, …

Difference = +3, so compare with 3n: 3, 6, 9, 12. Each term is 2 more.   nth term = 3n + 2   (M1 for 3n + k · A1)

Check: n = 1 gives 5 ✓, n = 4 gives 14 ✓.

Worked example: 20, 14, 8, 2, … (decreasing)

Difference = −6, so compare with −6n: −6, −12, −18, −24. Each term is 26 more.   nth term = 26 − 6n

✗ n + 3 for 5, 8, 11, 14. That adds 1 each time, not 3.
✗ 6n + 26 for 20, 14, 8, 2. A decreasing sequence needs a negative coefficient of n.
✓ The coefficient of n is always the common difference, sign included.

Using the nth term: is a number in the sequence?

Spec 3.1C · 2015 Edexcel Jan 4HR Q5(a) (old spec)

Set the nth term equal to the number and solve for n. The number is in the sequence only if n comes out as a positive whole number.

  1. Write nth term = the number.
  2. Solve for n.
  3. If n is a positive integer, the number is term n. If not, it is not in the sequence. Say so, and give the reason.
  4. For "the first term greater than 200", solve as an inequality and round n up.

Worked example: is 100 a term of 3n + 2?

3n + 2 = 100, so 3n = 98, so n = 32.67 (to 2 d.p.). Not a whole number, so 100 is not in the sequence. It falls between term 32 (98) and term 33 (101).

Worked example: the first term of 8n − 3 that is greater than 200

8n − 3 > 200, so n > 25.375, so n = 26. The term is 8 × 26 − 3 = 205.

Arithmetic sequences: a, d and the nth term

Spec 3.1A, 3.1B (Higher)

In an arithmetic sequence the first term is a and each step adds d, so the nth term has had (n − 1) steps added.

nth term of an arithmetic sequence — memoriseun = a + (n − 1)da = first term · d = common difference · n = position · NOT on the formula sheet

It is the same rule as dn + (a − d), just written a different way: a + (n − 1)d = dn + (a − d). For 5, 8, 11, … it gives 5 + 3(n − 1) = 3n + 2.

d can be negative (a decreasing sequence) or a fraction. The 20th term of 7, 4.5, 2, … is 7 + 19 × (−2.5) = −40.5.

✗ u20 = a + 20d. To get from term 1 to term 20 you take 19 steps.
✓ u20 = a + 19d.

Finding a and d from two terms

Spec 3.1A (Higher) · 2016 Edexcel SAM 1H Q23

Each term you are given makes one equation in a and d. Two terms give a pair of simultaneous equations.

  1. Write each given term as a + (n − 1)d = its value.
  2. Subtract the equations: the a's cancel and leave a multiple of d.
  3. Find d, then substitute back to find a.

Worked example: the 2nd term is 7 and the 5th term is 19

a + d = 7 and a + 4d = 19   (M1)

Subtract: 3d = 12, so d = 4   (A1). Then a = 7 − 4 = 3   (A1)

The sequence is 3, 7, 11, 15, 19, … ✓

Shortcut: from the 2nd term to the 5th is 3 steps, and the value rises by 12, so d = 12 ÷ 3. In SAM 1H Q23, the 4th term is 17 and the 10th is 35: 6 steps, a rise of 18, so d = 3 and a = 17 − 3 × 3 = 8.

The sum of an arithmetic series

Spec 3.1C (Higher) · 2016 Edexcel SAM 1H Q23 · 2018 Edexcel May 2H Q23

A series is the terms of a sequence added together. For an arithmetic series there is a formula for the sum of the first n terms, and it is on the formula sheet.

Sum of an arithmetic series — on the formula sheetSn = n/2 [2a + (n − 1)d]Sn = sum of the first n terms · a = first term · d = common difference
Sum using the last term — memoriseSn = n/2 (a + l)l = the last term added · useful when you know where the series ends
  1. Identify a, d and n (the number of terms, not the last term).
  2. Substitute and write the substitution down: that line is the method mark.
  3. Work out the square bracket first, then multiply by n/2.

Worked example: the sum of the first 50 terms of 4 + 7 + 10 + 13 + …

a = 4, d = 3, n = 50

S50 = 50/2 [2 × 4 + 49 × 3] = 25 × [8 + 147] = 25 × 155 = 3875   (M1 · A1)

Worked example: SAM 1H Q23 finished

a = 8, d = 3:   S50 = 25 × [16 + 49 × 3] = 25 × 163 = 4075

Or: the 50th term is 8 + 49 × 3 = 155, so S50 = 25 × (8 + 155) = 4075.

✗ Putting the last term in as n. n is how many terms there are.
✗ n/2 × 2a + (n − 1)d, with the bracket missing, so only 2a gets multiplied by n/2.
✓ Brackets exactly as on the formula sheet, and the square bracket worked out first.

Sums of multiples, and sums between two limits

Spec 3.1C (Higher)

To add up a run of terms, first find how many there are, then use Sn = n/2 (a + l).

  1. Find the first and last terms in the range.
  2. Number of terms n = (last − first) ÷ d + 1. The "+ 1" counts the first term.
  3. S = n/2 × (first + last).

Worked example: the sum of all the multiples of 7 between 100 and 300

First multiple: 105 (7 × 15). Last: 294 (7 × 42).

n = (294 − 105) ÷ 7 + 1 = 27 + 1 = 28 terms

S = 28/2 × (105 + 294) = 14 × 399 = 5586

✗ n = (294 − 105) ÷ 7 = 27. That counts the gaps, not the terms, and loses one.
✓ Check with a small case: from 7 to 21 in 7s is (21 − 7) ÷ 7 + 1 = 3 terms: 7, 14, 21.

Finding n when the sum is given

Spec 3.1C (Higher), with 2.7C

If Sn is known and n is not, the formula becomes a quadratic in n. Solve it, and keep only the positive whole-number answer.

  1. Substitute a and d into Sn = n/2 [2a + (n − 1)d], leaving n as a letter.
  2. Set it equal to the given sum, multiply out and rearrange to = 0.
  3. Solve the quadratic (factorise or use the formula).
  4. Reject a negative or fractional n. For "how many terms before the sum first exceeds …", round up.

Worked example: how many terms of 3 + 7 + 11 + … add up to 210?

n/2 [6 + 4(n − 1)] = n/2 (4n + 2) = n(2n + 1) = 2n2 + n   (M1)

2n2 + n = 210, so 2n2 + n − 210 = 0   (A1)

(2n + 21)(n − 10) = 0, so n = 10 or n = −10.5   (M1)

n must be a positive whole number, so n = 10   (A1). Check: S10 = 5 × (6 + 36) = 210 ✓

Harder problems: when a and d are both unknown

Spec 3.1 (Higher) · 2018 Edexcel May 2H Q23

Turn each piece of information into an equation in a and d, then solve them together, exactly as with any simultaneous equations.

  1. A term gives a + (n − 1)d = value. A sum gives n/2 [2a + (n − 1)d] = value.
  2. Simplify each equation: divide out common factors.
  3. Solve simultaneously, then answer the actual question, which is often a different sum.

Worked example: the 5th term is 14 and the sum of the first 10 terms is 155

a + 4d = 14   and   10/2 [2a + 9d] = 155, so 2a + 9d = 31

Double the first: 2a + 8d = 28. Subtract: d = 3, then a = 14 − 12 = 2.

How 2018 2H Q23 worked: S48 = 4 × S36, find S30

24(2a + 47d) = 4 × 18(2a + 35d) = 72(2a + 35d)

48a + 1128d = 144a + 2520d, so 96a + 1392d = 0, so 2a + 29d = 0 (÷ 48)

S30 = 15(2a + 29d) = 15 × 0 = 0. You never need a and d separately. The positive and negative terms cancel.

✗ Giving up because there are "two unknowns and one equation". Look at what is asked. S30 needed only the combination 2a + 29d.
✓ Write S30 = 15(2a + 29d) early, and look for that bracket in your working.

Sequences in context

Spec 3.1C, 3.1B (Higher)

A pattern that grows by the same amount each time is an arithmetic sequence. Decide what a, d and n mean in the story before you use a formula.

  • "How many in pattern/row/week n?" That is a term: un = a + (n − 1)d.
  • "How many altogether in the first n?" That is a sum: Sn.

Worked example: a theatre has 20 seats in row 1, and each row has 2 more seats than the row in front. There are 25 rows.

Row 25: 20 + 24 × 2 = 68 seats (a term)

Total: S25 = 25/2 × (20 + 68) = 12.5 × 88 = 1100 seats (a sum)

Sequences that are not arithmetic

Spec 3.1A (Foundation): odd, even, squares, multiples and powers

If the differences are not constant, the sequence is not arithmetic, so neither a + (n − 1)d nor Sn applies.

  • Squares 1, 4, 9, 16, … have nth term n2. Anything like n2 + 3 or (n + 1)2 is a square pattern shifted.
  • Powers such as 2, 4, 8, 16, … (nth term 2n) multiply by the same number each time.
  • Odd numbers are 2n − 1, even numbers are 2n, and multiples of k are kn.

4MA1 asks you to generate terms from rules like these and to recognise them. It does not ask you to find the nth term of a quadratic sequence, or to sum a geometric series. Those belong to other courses.

✗ Using Sn = n/2 [2a + (n − 1)d] to add up 1 + 4 + 9 + 16 + …. The formula only works when the differences are constant.
✓ Check the differences before you reach for a formula.

04Understanding it

U1

Why is the number in front of n in a linear nth term always the common difference?

Show answer

Each time n goes up by 1, dn goes up by exactly d, and the constant stays the same. So consecutive terms differ by d.

That is why you can read d straight off the sequence, and why a decreasing sequence must have a negative coefficient: 26 − 6n drops by 6 each time.

U2

Why is the formula un = a + (n − 1)d and not a + nd?

Show answer

The first term is a itself, with no steps added. The 2nd term has 1 step, the 3rd has 2, and so the nth has (n − 1) steps.

A quick check: n = 1 must give a. a + (1 − 1)d = a ✓, but a + 1d would already be the 2nd term.

U3

The nth term is 5n − 3. Explain how you know that 72 is a term but 75 is not.

Show answer

5n − 3 = 72 gives 5n = 75, so n = 15, a whole number. So 72 is the 15th term.

5n − 3 = 75 gives 5n = 78, so n = 15.6. There is no "15.6th term", so 75 is not in the sequence. Every term is 3 less than a multiple of 5, so ends in 2 or 7, and 75 does not.

U4

Why does Sn = n/2 (a + l) work? Use 1 + 2 + 3 + … + 100.

Show answer

Pair the first and last terms: 1 + 100 = 101. The second and second-last: 2 + 99 = 101. Every pair adds to the same total, a + l, because as one term goes up by d the other goes down by d.

There are 100 terms, so 50 pairs: 50 × 101 = 5050. In general, n/2 pairs, each worth (a + l). The formula-sheet version is the same thing with l = a + (n − 1)d put in.

U5

Why does "find n when Sn is given" always lead to a quadratic, and why do you throw one answer away?

Show answer

Sn = n/2 [2a + (n − 1)d] has n outside the bracket and n inside it. Multiplying out gives an n2 term, so it is a quadratic.

The algebra gives two roots, but n counts terms, so it must be a positive whole number. A negative or fractional root has no meaning and is rejected, with a reason.

U6

What is the difference between an arithmetic sequence and an arithmetic series? Give an example of each.

Show answer

A sequence is the list: 4, 7, 10, 13, …. Questions about it ask for a term, or the nth term.

A series is the terms added: 4 + 7 + 10 + 13 + …. Questions about it ask for a sum, Sn. If a question says "series", expect to use the formula-sheet sum.

U7

A student says the nth term of 4, 7, 12, 19, 28 is 3n + 1, because it "starts by going up in 3". What is wrong?

Show answer

The differences are 3, 5, 7, 9. They are not constant, so it is not an arithmetic sequence and no rule of the form dn + c can fit it. 3n + 1 gives 4, 7, 10, and the third term is already wrong.

It is n2 + 3. Always look at more than one difference. On 4MA1 you would be given this rule and asked to use it, not to find it.

U8

In 2018 2H Q23 the sum of the first 30 terms was 0. How can a sum of 30 terms be zero?

Show answer

The terms can be negative. 2a + 29d = 0 means a = −14.5d, so if d = 1 the series is −14.5 − 13.5 − … + 13.5 + 14.5. The first term and the 30th cancel, as do the 2nd and 29th, and so on.

In the pairing picture, a + l = 0, so every pair adds to zero, and n/2 × (a + l) = 0.
